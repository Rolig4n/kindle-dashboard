**Estrutura do projeto (`kindle-dashboard.zip`):**

```
kindle-dashboard/
├── Dockerfile
├── docker-compose.yml
├── .env.example          ← copie para .env e preencha
├── backend/
│   ├── server.js         ← Express: 5 endpoints de API
│   └── package.json
├── frontend/
│   └── public/
│       └── index.html    ← dashboard completo em HTML puro
└── docs/
    └── GUIA.md           ← passo a passo completo
```

**Para colocar no ar, são basicamente 4 comandos no servidor:**

```bash
cp .env.example .env
nano .env              # preenche OWM_API_KEY e OWM_CITY
docker compose up -d --build
# acessa http://IP_DO_SERVIDOR:3000 no Kindle
```

---

**Pontos que ficaram configuráveis para você ajustar depois:**

- **`HOME_CLIMATE_URL`** — assim que você tiver o container de sensores da casa pronto, é só colocar a URL no `.env` e reiniciar. O guia mostra o formato JSON esperado.
- **Galeria de imagens** — coloque as URLs no `GALLERY_URLS` separadas por vírgula.
- **Feeds RSS** — está com G1 e UOL por padrão, mas o guia lista outras opções brasileiras.

O guia (`GUIA.md`) cobre toda a parte do Kindle com KOReader, incluindo como abrir o navegador, definir a página inicial e manter a tela sempre ligada.
